# Brand marks

`powered-by-giphy.png` is the official GIPHY wordmark. It is the last frame of the logo published in Giphy's public Android SDK:

https://github.com/Giphy/giphy-android-sdk/blob/main/sdk_logo.gif

The GIF picker shows that mark beside the words "Powered by". GIPHY's API terms require the attribution. Do not redraw the mark.
